# Примеры данных

[К описанию проекта](../README.md) · [Схема данных и пайплайн](../docs/data-and-pipeline.md)

Все компании, котировки, новости и операции в этой папке синтетические. Пример описывает одну позицию: две покупки, сплит, дивиденд и частичную продажу.

## Входные данные

| Файл | Что внутри |
|---|---|
| [01_news.json](01_news.json) | Новости и раскрытия, источники, время публикаций, исправления и дубли |
| [02_market.json](02_market.json) | Инструменты, котировки, индексы рынка и отрасли, сплит и дивиденд |
| [03_user_actions.json](03_user_actions.json) | Счёт, начальные остатки, операции, запрос инвестора, тезис и правила |

## Результаты обработки

| Файл | Что внутри |
|---|---|
| [04_calculated.json](04_calculated.json) | Состояния счёта, P&L, регрессия, аномалии, проверки тезиса и правил |
| [05_pipeline_and_knowledge.json](05_pipeline_and_knowledge.json) | Этапы обработки, пакет для LLM, эталон карточки, доказательства и сохраняемый вывод |

## Воспроизведение

Из корня репозитория:

```bash
python examples/build_demo.py
```

[build_demo.py](build_demo.py) пересоздаёт пять файлов и проверяет согласованность расчётов. Ожидаемый итог: **−377,60 ₽**, остаток **30 акций**. Поиск и вызов LLM не выполняются; формулировки карточки заданы как эталон.
